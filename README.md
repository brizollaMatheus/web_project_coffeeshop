# Triple Espresso Coffee Shop

**Descrição do Projeto**
Este projeto consiste em uma página web para uma cafeteria fictícia chamada Triple Espresso. A página apresenta informações sobre a cafeteria, receitas, opções de reserva e formas de contato.

O projeto foi desenvolvido utilizando HTML5 e CSS3, com foco em boas práticas de desenvolvimento web, organização de código utilizando a metodologia BEM (Block Element Modifier), estrutura semântica e estilização responsiva.

**Tecnologias Utilizadas**

HTML5
CSS3
Metodologia BEM
Flexbox
Posicionamento CSS
Google Fonts (Inter)
Normalize.css
